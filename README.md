# Personal portfolio

A responsive, single-page portfolio built with Next.js and configured for GitHub Pages.

## Make it yours

Edit `app/page.tsx` to update biography, projects, experience, contact details, and social links. Update the page title and description in `app/layout.tsx`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Publish on GitHub Pages

1. Create a new GitHub repository and push this project to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. The included workflow will publish the site automatically on every push to `main`.

The configuration works for both `username.github.io` repositories and regular project repositories such as `username.github.io/portfolio`.
